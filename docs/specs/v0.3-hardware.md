# V0.3 — Hardware

## Goal

Detect local hardware and classify into profiles that guide model selection.

## Features

- [x] RAM, VRAM, CPU detection
- [x] Inference backend detection (CUDA, Metal, CPU)
- [ ] Inference backend detection (ROCm) — deferred
- [x] Profile classification: Tiny, Standard, Workstation

## Acceptance Criteria

- [x] Probe returns RAM bytes via `OSProber` (verified in tests)
- [x] Profile assigned matches [architecture/hardware.md](../architecture/hardware.md) tiers (unit tests)
- [x] CPU-only machine classified as Tiny (unit tests)
- [ ] Boot stdout demo (`cmd/` probe) — deferred; use `go test ./internal/hardware/...`

## Out Of Scope

- Model assignment logic (uses profile in registry v0.5+), scheduler integration
- ROCm detection (deferred to future release)

## Demo

```bash
go test ./internal/hardware/...
```

Library API: `hardware.ProbeAndClassify()` for programmatic use.

## Dependencies

- v0.2 Registry
