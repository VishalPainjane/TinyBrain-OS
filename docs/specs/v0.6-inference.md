# V0.6 — Inference

## Goal

Real GGUF inference via llama.cpp adapter implementing InferenceProvider.

## Features

- [x] llama.cpp CGO adapter — CPU load/unload + Generate; wired to runtime (009c)
- [x] GGUF model load via mmap — **partial (009a+009b):** CPU CGO path; integration test optional (`TB_TEST_GGUF_PATH`)
- [x] Single prompt generate call — **009b:** `LlamaProvider.Generate`; greedy integration verified
- [ ] GPU offload on CUDA-capable hardware

## Acceptance Criteria

- [x] One real generate call returns tokens from local GGUF file
- [x] TTFT and TPS measurable on Standard profile — **verified** (Linux WSL integration; SmolLM2-135M Q4_K_M)
- [x] Scheduler still has zero llama.cpp imports

## Out Of Scope

- KV compression, multi-model concurrent inference, cloud providers
- SaveContext / RestoreContext (task 011)

## Demo

Load a small GGUF model via `ModelRuntime` (`NewIntegratedModelRuntime`), send one prompt, receive complete response. Direct `LlamaProvider.Generate` also supported.

## Dependencies

- v0.4 Runtime, v0.5 Model Registry
