# V0.6 — Inference

## Goal

Real GGUF inference via llama.cpp adapter implementing InferenceProvider.

## Features

- [x] llama.cpp CGO adapter — **partial (009a):** load/unload only; Generate stub; not wired to runtime
- [x] GGUF Q4_K_M model load via mmap — **partial (009a):** CPU CGO path; integration test optional (`TB_TEST_GGUF_PATH`)
- [ ] Single prompt generate call
- [ ] GPU offload on CUDA-capable hardware

## Acceptance Criteria

- [ ] One real generate call returns tokens from local GGUF file
- [ ] TTFT and TPS measurable on Standard profile
- [x] Scheduler still has zero llama.cpp imports

## Out Of Scope

- KV compression, multi-model concurrent inference, cloud providers

## Demo

Load a small GGUF model, send one prompt, receive streamed or complete response.

## Dependencies

- v0.4 Runtime, v0.5 Model Registry
