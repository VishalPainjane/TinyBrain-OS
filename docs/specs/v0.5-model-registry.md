# V0.5 — Model Registry

## Goal

Persistent model metadata storage for paths, sizes, and memory budgets.

## Features

- [x] Model metadata persistence (bbolt via `go.etcd.io/bbolt`)
- [x] models.yaml seed format support (bootstrap when store empty)
- [x] List models with resource estimates

## Acceptance Criteria

- [x] Model definitions survive process restart
- [x] List shows path, size, memory budget per model
- [x] Registry interface unchanged from v0.2 (adapter swap only; `Close()` additive)

## Implementation

- `ModelStore` interface with `InMemoryStore` and `BboltStore`
- `NewModelRegistry()` — in-memory (tests, dev)
- `NewBboltModelRegistry(dbPath, seedPath)` — persistent (runtime at v0.6)
- `LoadModelsYAML(path, store)` — seed loader
- Gob-encoded values in bbolt bucket `models`

## Out Of Scope

- Hugging Face integration, automatic model download

## Demo

```bash
go test ./internal/registry/...
```

Register models via `NewBboltModelRegistry`, close, reopen — definitions persist. Empty store + `seedPath` loads `models.yaml`.

## Dependencies

- v0.2 Registry (in-memory interface)
- v0.3 Hardware (profile-aware listing — optional)
