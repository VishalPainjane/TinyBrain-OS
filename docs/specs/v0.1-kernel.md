# V0.1 — Kernel

## Goal

Establish the process model and process table as kernel primitives — the OS foundation for all future subsystems.

## Features

- [x] ProcessState type with 7 lifecycle states
- [x] ProcessState unit tests
- [x] Process table with CRUD and O(1) PID lookup
- [x] Process table unit tests

## Acceptance Criteria

- [x] ProcessState type exists, strongly typed, all 7 states defined
- [x] ProcessState.String() returns canonical names
- [x] ProcessState.Valid() validates range
- [x] Process table supports Create, Get, List, UpdateState, Delete
- [x] Process lookup by PID is O(1)
- [x] All kernel tests pass: `go test ./internal/process/...`

## Out Of Scope

- Scheduler, runtime, event bus, registry, inference, agents

## Demo

```bash
go test ./internal/process/...
```

## Dependencies

None — first version.
