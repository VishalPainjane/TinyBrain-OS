# V0.7 — Scheduler

## Goal

MLFQ scheduler with preemption, token quanta, and VRAM-aware decisions.

## Features

- [ ] MLFQ Q0–Q3 queues
- [ ] Token quantum demotion
- [ ] Preemption of lower-priority processes
- [ ] Boost/aging anti-starvation
- [ ] Swap heuristic (idle > 10s)

## Acceptance Criteria

- [ ] Two competing tasks demonstrate preemption
- [ ] Queue depths visible in metrics
- [ ] Scheduler delegates all model ops to runtime interface

## Out Of Scope

- Full KV hibernation (v1.0), Kubernetes SwapPolicy CRD

## Demo

Submit high-priority task while low-priority task runs — observe preemption in process table.

## Dependencies

- v0.4 Runtime, v0.1 Process table, event bus
