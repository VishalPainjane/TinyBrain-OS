# V0.4 — Runtime

## Goal

Runtime shell with ModelRuntime and InferenceProvider interfaces; stub provider for testing.

## Features

- [x] ModelRuntime interface implementation (shell)
- [x] StubProvider returning canned responses
- [x] Load/unload/swap via interface (no real models)
- [x] Event emission on model state changes

## Acceptance Criteria

- [x] Swap two stub models without scheduler importing inference code
- [x] Generate returns structured response from stub
- [x] INV-001 and INV-008 satisfied in package imports

## Out Of Scope

- Real llama.cpp inference (v0.6), MLFQ scheduler (v0.7)

## Demo
