# V1.0 — Integrated Runtime

## Goal

Integrated local AI runtime product: kernel, registry, hardware, runtime, inference, scheduler, agents, and live telemetry on consumer hardware.

## Features

- [ ] All v0.1–v0.8 acceptance criteria met
- [ ] brain-top TUI with live process, queue, and resource panels
- [ ] KV save/load (basic hibernation)
- [ ] Benchmark suite: swarm vs monolith comparison
- [ ] Developer mode: `tinybrain run`

## Acceptance Criteria

- [ ] Dynamic load/unload/swap demonstrated on Standard profile
- [ ] Process table + scheduler + runtime + inference working together
- [ ] brain-top shows live agent states and VRAM/RAM bars
- [ ] Metrics: TPS, TTFT, swap latency recorded
- [ ] README quick start commands work

## Out Of Scope

- Kubernetes operator (post-v1.0), full KV compression pipeline, cloud providers

## Demo

Run `brain-top` while executing multi-step task — watch agents move through states live.

## Dependencies

- v0.1 through v0.8 complete

## Tasks

- Integration of all prior tasks
