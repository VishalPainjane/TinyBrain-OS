# V0.8 — Agents

## Goal

Plugin agent execution — end-to-end task pipeline with two sample agents via events.

## Features

- [x] Agent plugin contract implementation
- [x] Sample fleet: two agents from registry config (e.g., planner → coder workflow)
- [x] Structured JSON IPC between agents via event bus
- [x] Tool request routing to tool layer (stub acceptable)

## Acceptance Criteria

- [x] Task flows: submit → route → schedule → execute → complete
- [x] No hardcoded agent types in core
- [x] Peak VRAM < 3.6 GB on Standard profile for 2-agent demo

## Out Of Scope

- Browser/reasoner agents, RAG, autonomous loops, cloud fallback

## Demo

Submit task; two sample agents execute sequentially via events; structured JSON output returned.

## Dependencies

- v0.7 Scheduler, v0.6 Inference, v0.2 Registry
