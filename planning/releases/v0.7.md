# Release V0.7 — Scheduler and Memory Subsystems

**Status:** Shipped (tag `v0.7`)

## Goals

MLFQ scheduler, KV manager stub, Swap manager, and `brain-top` prototype.

## Features

- Q0–Q3 queues with per-level token quanta (32/64/128/256)
- Preemption when higher-priority work arrives
- Boost/aging every 500 tokens or 30s wall clock
- Swap idle heuristic (`ShouldSwap`, 10s threshold — policy only)
- `QueueDepths()` for telemetry
- `internal/kv` stub KV manager with `KVStored` / `KVLoaded` events
- `internal/swap` stub swap manager for VRAM→RAM tier moves
- `cmd/brain-top` read-only dashboard prototype
