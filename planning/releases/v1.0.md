# v1.0.0 Release Notes

**Date**: 2026-06-24

## Overview
TinyBrain OS v1.0 marks the completion of the Month 6 roadmap. The runtime is now fully integrated, hardware-aware, and capable of coordinating multiple LLM agents (Swarm workloads) over a shared inference engine natively from the local shell. 

## Completed Tasks
- `018-benchmark-suite`: End-to-end swarm vs monolith benchmarking harness to measure TTFT and TPS.
- `022-system-integration`: Full end-to-end plumbing of `cmd/tinybrain` with the kernel, models, and UI, ensuring clean imports and strictly enforced architectural boundaries.
- `023-brain-top-production`: Hardened the BubbleTea CLI dashboard to present production-ready telemetry across inference processes, resource utilization, scheduling queues, and memory footprint.
- `v1.0 paperwork`: Version bumps, testing verifications, and Tier B/C updates.

## New Features
- The `tinybrain run` and `tinybrain workflow` commands now fully exercise the MLFQ scheduler, event bus, and GPU dynamic loaders.
- System observability is feature-complete via the `brain-top` prototype command.
- Benchmarking tools available via `cmd/benchmark`.

## Demo / Verification
- Monolith and Swarm workloads have been demonstrated end-to-end.
- The global test suite passes cleanly, confirming no logic or package boundaries were breached.

## Lessons Learned
- Decoupling the inference provider from the scheduler via the Event Bus continues to pay dividends, allowing us to build the benchmark tool entirely outside the core.
- Native windows DLL injection for GPU support works flawlessly but demands strict CGO hygiene in tests.
