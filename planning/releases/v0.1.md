# Release V0.1 — Kernel

**Status:** Shipped (bundled in tag `v0.3`)

## Goals

Establish process model and process table as kernel primitives.

## Implemented Features

- ProcessState with 7 lifecycle states (String, Valid, All)
- Process table with Create, Get, List, UpdateState, Delete
- O(1) map-backed PID lookup with mutex protection

## Deferred Features

- Scheduler transition validation (owned by scheduler package)
- Process persistence across restarts

## Known Issues

(none)

## Lessons Learned

- Table-driven tests in `state_test.go` pattern scales well to `table_test.go`
- Forcing NEW state on Create prevents caller state injection bugs

## Architecture Impact

- `internal/process/` established as kernel owner of process state and table
- Foundation for scheduler and runtime consumers (Month 2+)

## Future Work

- Runtime updates to MemoryUsage/VRAMUsage fields on process records
- Process table persistence (v0.5+)
